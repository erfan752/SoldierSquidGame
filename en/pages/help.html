Getting Started

To get started, add the bot to your group; it will send a confirmation message once it has successfully joined.

Next, make the bot an admin — once it detects admin rights, it will send an installation confirmation message. (It's recommended to grant all required permissions so you don't run into issues later.)

After installation, the bot treats the current group owner as the Frontman (leader).

Game Commands

Command Description
شروع بازی Announces a new game and opens player registration, waiting for the next command from the Frontman or a VIP guest
شروع بازی کشتار Same as "Start Game", except rounds repeat until only one player remains alive.
بعدی Move to the next game / stage
اتمام بازی Ends the current game under any circumstances

Locks & Customization

Soldier comes with locks and customization features so groups can create a truly authentic Squid Game experience.

Locks:

Command Description
ضد درگیری فعال Detects abusive messages and deletes them
ضد درگیری غیرفعال Turns off detection and deletion of abusive messages
واکنش با گیف فعال Turns on GIF reactions from Soldier in the group
واکنش با گیف غیرفعال Turns off GIF reactions from Soldier in the group
نظرسنجی فعال Enables polls between games
نظرسنجی غیرفعال Disables polls between games

Customization:

Command Description
تنظیم پیام شرکت کردن + (your message text) Set a custom message shown when a player joins the game. Available placeholders: (number) (name). Example: Player number (number), named (name), has joined the game
حذف شرکت کردن Removes the custom join message and restores the default
تنظیم پیام کشته شدن + (your message text) Customizes the message shown when a player is eliminated
حذف پیام کشته شدن Removes the custom elimination message and restores the default

Using the Chatbot

Soldier comes with its own built-in chatbot you can talk to.

To chat, start your message with the word سرباز followed by your message.

Example: سرباز سلام خوبی؟؟

Note: without a subscription, each user can send one message; with a subscription, you can send up to 5 messages to Soldier.

Important Notes

Soldier automatically behaves as follows during a game:

  • If the bot has permission to manage member restrictions in the group, it mutes eliminated players.
  • Each player is assigned a unique number during registration; once taken, no other player can use that number.
  • Eliminated players are unmuted automatically once the game ends.

Bale vs Telegram

Soldier Squid Game is officially available on both Telegram and Bale. Guides and commands are identical on both; the difference lies in emoji style, speed, and appearance.

FAQ

How do I add the bot to my group?

In your group settings, under "Add Member", search for and add soldiersquidgame_bot, then make it an admin.

Is using Soldier free?

Soldier gives new groups a free trial subscription; once it expires, you can purchase a subscription to keep using Soldier for more days.

What should I do if I run into a problem?

You can raise your issue in the support group for your platform.

Support

If you run into any issues or have questions about Soldier Squid Game, join the support group for your platform and ask your question there.
