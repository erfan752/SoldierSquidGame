Setup & Getting Started

To get started, add the bot to your group; it will send you a confirmation message once it has joined successfully.

Next, make the bot an admin; it will send an installation confirmation message afterward. (We recommend granting all necessary permissions so you don't run into issues later.)

After installation, the bot treats the current group owner as the Frontman.

Game Commands

Command Description
Start Game Announces a new game and opens registration for players, then waits for the next command from the Frontman or a VIP guest.
Start Elimination Game Same as "Start Game", except rounds repeat until only one player remains alive.
Next Move to the next game/stage
End Game Ends the current game under any circumstances

Frontman Commands

Command Description
#PlayerList Shows the list of all players in the game
#AlivePlayers Shows the list of players still alive in the game
Add Guest + (reply) Adds that player to the VIP guest list
Remove Guest + (reply) Removes that guest from the VIP guest list
Transfer Frontman + (reply) Fully transfers Frontman status to the replied-to person
Ban From Joining + (reply) Prevents that player from joining during registration
Allow Joining + (reply) Removes that player's join restriction
Eliminate + (reply) Manually eliminates that player from the game

Locks & Customization

Soldier is equipped with locks and customization features that give groups everything needed for an authentic Squid Game experience.

Locks:

Command Description
Anti-Conflict On Detects messages containing insults and removes them
Anti-Conflict Off Disables the insult-detection and removal system
GIF Reactions On Turns on GIF reactions from Soldier in the group
GIF Reactions Off Turns off GIF reactions from Soldier in the group
Polls On Enables polls between games
Polls Off Disables polls between games

Customization:

Command Description
Set Join Message + (your text) Customize the message shown when a player joins the game. Available placeholders: (number) (name). Example: Player number (number) named (name) has joined the game
Remove Join Message Removes the custom join message and reverts to the default
Set Elimination Message + (your text) Customize the message shown when a player is eliminated
Remove Elimination Message Removes the custom elimination message and reverts to the default

Using the Chatbot

Soldier comes with a built-in chatbot you can talk to.

To chat, start your message with the word Soldier and continue with your message.

Example: Soldier hey, how are you?

Note: without a subscription, each user can send one message; with a subscription, you can send up to 5 messages to Soldier.

Important Notes

Soldier automatically applies these behaviors during games:

  • If the bot has permission to manage member restrictions, it mutes eliminated players.
  • Each player is assigned a unique number upon registration; once taken, no other player can use that number.
  • Eliminated players are unmuted once the game ends.

Bale vs. Telegram

Soldier Squid Game is officially available on both Telegram and Bale, with identical commands and guides on both platforms; the differences lie in emoji style, speed, and appearance.

Subscription & Premium Features

A subscription removes all of Soldier's limitations and unlocks the core features. You can visit the Subscription Plans page to purchase a subscription.

Frequently Asked Questions

How do I add the bot to my group?

In your group settings, under Add Member, search for the username soldiersquidgame_bot and add it as an admin.

Is Soldier free to use?

Soldier gives new groups a complimentary subscription; once it expires, you can purchase a subscription to keep using Soldier for more days.

What should I do if I run into a problem?

You can raise your issue in the support group.

Support

If you run into a problem or have a question about Soldier Squid Game, you can join the support group for your platform and ask your question there.
