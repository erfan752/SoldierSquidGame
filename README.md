# SoldierSquidGame | سرباز بازی مرکب
**نخستین ربات سرباز بازی مرکب در پیامرسان بله است که می‌تواند گروه شمارا بسیار جذاب کند. با این ربات شما میتوانید چندین بازی از سریال اسکویید گیم را در گروه با اعضا خود بازی کنید.**


## قابلیت های ربات سرباز :
- 🎭پیوستن هر کاربری به بازی تا سقف ۴۵۶ بازیکن
- 🥸 داشتن یک رئیس اصلی برای مدیریت روند
- 🤩 قابلیت گفتگو با چت بات سرباز
- ⚓️ اعلام برنده خودکار
- 🩶 سکوت زدن بازیکنان حذف شده و برداشتن حین اتمام بازی
