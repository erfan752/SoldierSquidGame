## 📰 قابلیت‌های ربات سرباز

- 🎭 امکان شرکت کاربران در بازی تا سقف **۴۵۶ بازیکن**
- 🥸 سیستم **فرانت‌من** برای مدیریت روند بازی
- 🤖 قابلیت گفتگو با چت‌بات هوشمند سرباز
- 🏆 اعلام خودکار برنده بازی
- 🔇 محدود کردن بازیکنان حذف‌شده و آزادسازی پس از پایان بازی
- 🎮 اجرای بازی‌های متنوع از بازی مرکب در گروه
- ⚡ سرعت بالا حتی در چندین استفاده همزمان 


## 🦑 نحوه برگزاری بازی در گروه

1. ابتدا ربات را به گروه خود اضافه کنید. پس از نصب، پیام موفقیت به صورت خودکار ارسال می‌شود.

> ⚠️ در حال حاضر ربات برای شروع عمومی فعال نیست و امکان اضافه کردن آن به گروه وجود ندارد.

2. به صورت پیش‌فرض، سرباز مالک گروه را به عنوان **فرانت‌من** انتخاب می‌کند.

3. برای انتقال ریاست، دستور زیر را روی پیام فرد موردنظر ریپلای کنید:

```
انتقال رئیس
```

4. فرانت‌من برای دریافت لیست دستورات می‌تواند دستور زیر را در گروه ارسال کند:

```
/کامند
```

> تمامی دستورات و مراحل بازی توسط سرباز در طول اجرای بازی اعلام می‌شود.
